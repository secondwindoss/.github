## Projects

| Project | What it is | Install |
|---|---|---|
| [diskcache-community](https://github.com/secondwindoss/diskcache-community) | Disk and file backed persistent cache for Python, built on SQLite, with a Django backend | `pip install diskcache-community` |
| [streaming-community](https://github.com/secondwindoss/streaming-community) | Fast, accurate streaming of training data from cloud storage for PyTorch | `pip install streaming-community` |
| [sqlx](https://github.com/secondwindoss/sqlx) | General purpose extensions to Go's `database/sql` | `go get github.com/secondwindoss/sqlx` |

## Get involved

- **Report a bug or ask a question** in the issue tracker of the project concerned.
- **Report a vulnerability** privately through the Security tab of that repository. See [SECURITY.md](https://github.com/secondwindoss/.github/blob/main/SECURITY.md).
- **Send a pull request.** Small, tested changes with a changelog entry are easiest to merge. See [CONTRIBUTING.md](https://github.com/secondwindoss/.github/blob/main/CONTRIBUTING.md) and the project's own guide.
- **Suggest a project** that needs a second wind by opening an issue in this repository.
